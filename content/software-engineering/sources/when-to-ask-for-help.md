# When to ask for help

1. Set a timebox before you start: if you are still stuck when it runs out, ask for help.
2. A good question says what you are trying to achieve, what you expected, what happened instead, and what you already tried.
3. Including the exact error message and a minimal reproduction lets others help quickly.
4. The XY problem is asking about your attempted solution instead of the real problem, which can send helpers in the wrong direction.
5. Asking in a shared channel instead of a private message lets others learn from the answer and lets more people help.
6. Staying stuck for days on something a teammate could explain in minutes costs the team more than the interruption.
